# 🎉 RSVP Invitation for Kids

An interactive web-based invitation designed as a simple and playful application for RSVPing to a children's birthday party. It allows guests to confirm their attendance while providing the organizer with an overview of the number of confirmed guests. Guests can also browse gift ideas directly within the invitation.

The goal was to create a modern alternative to the classic paper invitation that would be not only visually appealing, but also practical and interactive. The primary focus was on ease of use on mobile devices, where guests are most likely to open the invitation and confirm their attendance.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3 / SCSS**
- **Vanilla JavaScript (ES6+)**
- **API integration** – sending and processing RSVP responses
- **QR code** – for the printable version

---

## ⚙️ App Features

- RSVP form for confirming attendance
- First and last name validation
- Automatic gift idea slideshow
- Error and confirmation message handling
- Responsive design for mobile phones, tablets, and desktop computers
- QR code for accessing the digital invitation from the printed version

---

## 📱 Responsive Design

The invitation is designed to provide a smooth experience across different screen sizes, with a particular focus on mobile devices.

The layout and individual elements adapt to mobile phones, tablets, and desktop screens while maintaining clear typography and easy navigation.
